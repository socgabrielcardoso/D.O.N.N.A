# Roadmap

## v0.2 — desktop operations
- accessibility-first Windows UI Automation before coordinate clicking;
- system tray and configurable global hotkey;
- richer First Run settings UI;
- signed packaged Windows release validation on Gabriel's Acer hardware;
- Linux launcher validation on the Kali notebook.

## v0.3 — knowledge and connectors
- incremental document RAG with PDF/code ingestion;
- Gmail/Outlook/Calendar/Drive/OneDrive/GitHub connectors behind explicit permission scopes;
- corporate-data boundary policies and local-only routing controls.

## v0.4 — agentic automation
- verified browser actor with transaction confirmation;
- Planner → Executor → Validator plans for multi-step tasks;
- screen element map using accessibility APIs + OCR/vision fallback;
- proactive monitors with rate limits and user-defined notification policy.

## v1.0 criteria
A release is only called stable after packaged binaries, microphone/audio, wake word, cancellation, provider fallback, memory, risk confirmations and install/repair flows are verified on physical Windows and Linux target machines.
